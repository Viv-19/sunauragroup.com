# SunAura Project - Agent Instructions

## gstack Skills Integration
This repository is configured to use **gstack** (`https://github.com/garrytan/gstack`).

Available gstack slash-command skills:
- `/office-hours` - Product framing & initial consultation
- `/autoplan` - Full strategic, design, DX, and engineering review pipeline
- `/plan-ceo-review` - Scope analysis and 10-star product vision
- `/plan-eng-review` - Engineering architecture, data flow, & edge case verification
- `/plan-design-review` - UI/UX & design system review
- `/design-html` - Production HTML/React layout builder
- `/review` - Staff engineer code review & auto-fixing bugs
- `/qa` - Complete QA & browser verification
- `/ship` - Release management & PR verification
- `/browse` - Headless/Headed browser automation

## Ethos & Engineering Rules
1. **Search Before Building** — Inspect existing components and utilities in `frontend/src` before creating new ones.
2. **User Sovereignty** — Recommendations are provided to the user, who makes key strategic decisions.
3. **Completeness & Quality** — Always write clean, error-handled code with full verification.
