# SunAura - Authorized Racold Distributor

SunAura is a premium web application designed for an authorized distributor of Racold water heating solutions. The platform showcases a comprehensive range of products including storage geysers, tankless geysers, heat pumps, and solar water heaters.

## Key Features

- **Premium UI/UX**: A modern, responsive design built with React, Tailwind CSS, and Lucide Icons.
- **Product Catalog**: Detailed information and features for all major Racold product categories.
- **Dynamic Projects Showcase**: Automated image slider showcasing successful installations and large-scale projects.
- **Instant Inquiries**: Integration with WhatsApp for direct customer inquiries from any product or category page.
- **SEO Optimized**: Built with performance and visibility in mind.

## Tech Stack

- **Frontend**: React.js, React Router
- **Styling**: Tailwind CSS, Shadcn UI
- **Icons**: Lucide React
- **Notifications**: Sonner

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Viv-19/SunAura.co.in.git
   ```

2. Navigate to the frontend directory:
   ```bash
   cd SunAura.co.in/frontend
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

The application will be available at `http://localhost:3000`.
